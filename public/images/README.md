# Images Zenin

Placeholders SVG pour le développement. Remplacez par des photographies WebP ou JPEG optimisées :

| Fichier | Usage |
|---------|--------|
| `hero-haltere.*` | Hero accueil : haltère seule, fond transparent, ratio ~4:5, zone flottante |
| `hero-zenin.*` | (legacy) scène intérieure si besoin |
| `zenin-10kg.svg` … `zenin-25kg.svg` | Fiches haltères |
| `zenin-detail.*` | Texture béton, section matière |
| `banc-zenin.*`, `rack-zenin.*`, `tapis-zenin.*` | Équipement |
| `atelier-zenin.*` | Page à propos |

Conserver les mêmes chemins dans `lib/products.ts` ou mettre à jour les `src` après remplacement.

Recommandations : fond clair, lumière naturelle, ombres nettes sur le béton.
